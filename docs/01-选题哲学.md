# 01 · 选题哲学

## 一条内容主线

当前 repo 只做 Apodex Science track：研究实验室、研究者与科研团队如何定义问题、判断证据、选择下一步，并识别 AI 输出的边界。

领域是 instance，不是栏目。biology、chemistry、materials、scientific computing、physics、earth/space 与 engineering 都可以进入同一套判断，只要它们带来真实研究任务或决策。

## 一个好选题需要什么

好选题从靠谱 source 出发，但“source 权威”只解决真实性起点，不自动等于内容价值。终审同时看：

1. 定义：具体问题、决策者、代价与未知分别是什么。
2. 研究相关性：实验、数据、工具、证据冲突、结果解释或下一步行动中，至少有一个真实任务。
3. 新意：新的张力、证据变化、未被说清的边界，或可公开验证的提问。
4. 可承接性：Apodex 能给出具体研究或 verification 视角，而非附和热点。
5. 推断纪律：source 明说的内容与我们的判断分开；没有一手材料时只写 hypothesis。

## 来源与动作

X、Reddit、RSS、News、官方记录与其他 web source 都只是发现入口。source 不锁 column，column 也不锁 action。

- X 候选可以做原创、reply、quote，或同时做原创与互动。
- Reddit 候选可以做原创 seed、Reddit reply，或两者兼有。
- RSS 与 News 先用作及时 signal，再回到它们指向的原始材料。
- C4 与 C6 的内部物料只由 Selene 提供；不进入自动外部采集。

## 排除边界

当前不做学术诚信与出版争议、撤回追踪、作者纠纷、泛 AI 口水、竞品 launch、方法炫技或只有“新”却没有明确问题的材料。单一熟悉叙事不能因为 prompt 里曾经出现过就占满日报；Judge 必须按定义、研究任务与行动价值逐条判断。
