# 01 · 选题哲学

> 就两条：**账号身份（主线）** + **PROBLEM-FIRST**。其余所有栏目/打分/纪律都从这两条推出来。

---

## 一、账号身份（主线）—— 解决身份漂移

**身份 = AI for〔science research labs + deeptech startups〕，verification 为内核。**
这两类 = AFP 两大 ICP 线 = 两大内容线。"我们就是 AI4 他们。"

- **领域(bio/材料/金融/监管)只做 instance，不做身份。** 今天 bio、明天材料，只要话术骨架/hashtag/互动人群一致，Phoenix 眼里仍是同一个号。散一次就学乱一次。
- **两大 ICP 命名**（走 hashtag + 系列名，不用 X List）：`Apodex4Science`（science labs）/ `Apodex4DeepTech`（deeptech startups）/ `ApodexSolvers`（C 端 UGC）。

## 二、PROBLEM-FIRST —— 内容立场

**先亮出 ICP 的一个真实 PROBLEM / 痛点 / 危险 → 让他刷到就 problem-aware →_之后_才说 solution 和 Apodex。**

- ❌ 不自卖自夸（找一篇"讲验证/深度研究重要"的论文 = 变相吹我们强）
- ❌ 不 showcase 论文当选题（arXiv 方法论文对这目标是错的源）
- ❌ 不夸人、不踩竞品（含垂类）
- ✅ 要的是"卧槽这就是我的痛 / 这太可怕了"——ICP 先对 problem 有痛感

## 凭什么这么定（证据，非结论）

- **Phoenix Retrieval（双塔）认 embedding**：身份越散越召不回对的 ICP。→ 所以要主线。
- **涨对的粉靠共鸣+深互动，不靠曝光**：$100k 帖 37 万曝光深互动仅 11、几乎不涨粉；6 月紧贴 verification 的实证内容 +1000 粉。→ 所以要 problem-first 的共鸣，不要自夸/蹭曝光。
- **bookmark 是本号王牌**（launch 帖 359 收藏）——能被收藏的是有参考价值的实证。
- **哑弹是可预测的**：thread 内部续推（candidate isolation 必死）、中文帖（英文 ICP 触达不到）、领域漂移热点。
