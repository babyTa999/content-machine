# 01 · 选题哲学

## 第 0 层：母问题

> **Who checked this — other than the person who made it?**
> 除了做出这个判断的人，还有谁检查过它？

一切收口回同一句：**这个判断有没有资格被相信**——注意不是"对不对"。

母问题的天然对手是**自评（self-review）**。张力全部来自这里。

八个 thesis 并列等于没有母问题，那是内容"散"的结构性原因，不是算子不够。母问题定义在 `config/pillars.yml` 的 `root_question`。

**赛道边界**：本 contract 当前只服务**科学研究赛道**。金融赛道（ECOA / Reg B / AML / 信贷）的母问题是监管型的，语法不同；战略文件明确两条赛道各自独立执行、不合并计算。混发会互相稀释受众。

## 第 1 层：一条内容主线

content-machine 以 Apodex 的产品能力和官网同构问题为起点。外部事件负责提供 timing、真实案例与一手证据，不能反过来定义品牌每天讲什么。

当前保留两条原创系列：

- **Design Choice**：从技术报告中的关键设计选择出发，讲清“为什么这样设计”以及它解决了什么真正困难的部分。
- **Problem Shape**：从官网同构的重型研究问题出发，再用报告、demo、benchmark 或内部案例解释 Apodex 为什么能承接。

Proof / verification 系列暂停。benchmark 只在确有新结果或必要事实核时使用，不作为日常母题。

## 第 2 层：两条常青引擎

EI1–EI5 全部事件驱动，没新闻的一周就断供。以下两条不依赖热点——热点只提供 timing，不提供选题。这是"源源不断"的结构保证。

### E1 · Missing Control（少了哪个对照）

`EI6_missing_control` → `PS10_missing_control` → `T2_independent_verification`

母表 `config/confound_library.yml` 是唯一选题来源。覆盖全部 STEM 六科（生物医药 / 材料 / 能源 / 化学 / 物理 / 计算机），依据战略文件 A1 范围。

每条必须填满**五个硬闸门字段**，缺一即拒：

- `discipline`
- `reported_metric`（一个被广泛报告的具名指标）
- `confound`（一个具名的替代解释）
- `control_or_report_item`（排除它所需的对照或报告项）
- `standard_source`（一份已公开发表的 reporting standard / checklist / best-practice review）

这五项使"复现性泛叙事"与"学术方法论文导读"在结构上无法进入——它们填不出前四项。

不需要懂六个学科：每科的混杂因素都已被人写成公开标准，这是检索任务而非自学任务。

### E2 · Cross-field Isomorphism（跨学科同构）

`EI7_cross_field_isomorphism` → `PS11_cross_field_isomorphism` → `T9_cross_domain_synthesis`

来自战略文件 A1：材料/能源的"结构-性能"优化与蛋白质/AAV 结构优化在计算范式上高度相似，技术栈可直接复用。内容层同样成立。

背书是落地页 `cross-domain evidence synthesis`，故 `capability_backing` 填 `website`。

## 第 3 层：算子（这条怎么写）

`editorial_intent` / `problem_shape` / `thesis` / `column` 四个字段全部回答"Apodex 凭什么能讲"，没有任何字段回答"落笔第一句是什么"。算子填这个空，定义在 `config/operators.yml`。

13 个算子逆向自 @ambient_xyz 2026-06-08 → 07-27 共 80 条帖：4 个 Tier 1 主力、4 个 Tier 2 机会型、2 个 Tier 3 格式层、1 个待改造、2 个已弃选（保留弃选口径）。

`OP11_boundary_self_disclosure` 是 `always_on`：每条原创必须带一句主动划界，这同时满足对外红线"不许偷偷加承诺"。

## 终审顺序

1. 多条来源实际描述的是哪个 canonical event？
2. 事件能否匹配一个 active editorial intent？
3. 官号为什么有资格讲？
4. Apodex 当前能否处理、演示，或是否已有内部证据支持？
5. 是否与官网展示的问题形态同构？
6. 普通目标读者能否立即理解？
7. 是否有一句可带走的判断和清晰视觉论点？
8. 本期是否已经使用过同一 canonical event 或同一叙事？

垂直专业问题若没有 capability、demo、benchmark 或内部案例支撑，只能作为洞察，不进入官号原创。

## 来源与归宿

每个 canonical event 在一份日报中只能有一个 `primary_destination` 和一个
`primary_action`。不同报道只是该事件的 mentions，不会各占一个栏目。

X、Reddit、RSS、News、官方记录和 web source 都是证据角色：

- `timing_signal`：说明为什么现在讲。
- `real_case`：提供真实用户问题或后果。
- `primary_record`：支撑事实与状态。
- `expert_context`：补充背景，不单独定义母题。
- `lead_only`：只用于发现线索，必须回到原始材料。

## 排除边界

默认排除：无能力支撑的垂直研究建议、学术方法论文、复现性泛叙事、泛 AI 幻觉、AI4AI、竞品 launch、匿名 Reddit 品牌案例、低 reach 互动、以及只有“新”但没有产品同构问题的材料。

### E1 与"学术方法论文 / 复现性泛叙事"的分界

两者仍然排除，E1 不是它们的例外通道。分界由 `PS10_missing_control.hard_gate` 的五个必填字段机械判定：

| | 排除项 | E1 准入 |
|---|---|---|
| 具名指标 | 无 | `reported_metric` 必填 |
| 具名替代解释 | 无 | `confound` 必填 |
| 可执行动作 | 无 | `control_or_report_item` 必填 |
| 一手标准背书 | 论文本身就是选题 | `standard_source` 只作背书，不作选题 |
| 产出对读者 | "科学有危机" | PI 明天回审稿意见能直接用 |

只要五项有一项空，即为泛叙事，拒。

### 科研诚信的降级口径

科研诚信 / 论文可复现性核查经战略文件第五节三条件测试后**正式排除在十年资源分配范围之外**，仅作为科学研究赛道学术获客渠道（顶刊论文背书）的自然延伸。

因此撤稿类选题降为 **Tier 3 机会型，每月上限 1 条**，且收口必须落在结构性验证而非诚信指控。频率一高，官号定位会从"帮你做研究"漂到"盯你造假"，对 Frontier Program signup 是反向的。

`config/pillars.yml` 的 `exclude` 已硬拦 academic misconduct / paper mill / plagiarism allegation / peer review fraud 四组关键词，此处约定为第二道线。
