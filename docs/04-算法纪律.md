# 04 · 算法纪律 —— 格式→信号映射 + 平台红线

> 选题定了之后，执行层要守的纪律。全部对着 X 算法机制（源：`Desktop/X 渠道运营.md` 算法拆解）。
> 🟢 硬机制 · 🟡 权重方向 · 🟠 旧版启发（稳妥做法）。

---

## 召回层（进别人的 feed）

- 🟢 **保持一致内容身份**——出圈靠 Phoenix Retrieval 双塔匹配。内容身份越清晰，越被召回给"爱看这类"的陌生人。（= 4 支柱纪律）
- 🟢 **别让内容和受众兴趣错位**——OON 召回是相似度驱动，错位=匹配不到对的人。
- 🟡 **语言统一**——candidate hydrator 有 language code 检测；主号纯英文。

## 过滤层

- 🟢 **前几小时最关键**——`AgeFilter` 删超时效阈值的推，没有"慢发酵"。发完盯前几小时互动。
- 🟢 **别用大众高频静音词**——`MutedKeywordFilter` 命中就剔。
- 🟢 **别重复发几乎一样的内容**——`DropDuplicatesFilter` + `RepostDeduplicationFilter`。（去重见 oracle）
- 🟠 **外链尽量放评论区**——旧版外链降权是硬规则，新版没在明文过滤器，仍是稳妥做法。P2 的 blog/report/GitHub 链接放首条评论。

## 内容理解层（Grox）

- 🟢 **别像 spam**——engagement bait（"点赞抽奖""转发就…"）、批量 @ 人 → spam detection + PTOS。
- 🟢 **让内容能被清晰归类**——主题明确有助 post-category classification 匹配。（= 4 支柱纪律）

## 打分·正信号（深互动）

- 🟡 **让人想 reply / quote / repost / DM 转发**——深互动权重 > favorite/click。
  结尾留钩子、抛可接话的观点、给能被截图引用的金句。
- 🟡 **让人想点开主页、想关注**——`profile_click` + `follow_author` 高价值。单条也要勾出"这号还有啥"。
- 🟡 **争取完读 / 停留**——`dwell` / `cont_dwell_time` 正信号。**开头 1–2 句必须抓人**，长推别注水。
- 🟡 **视频够长且被看完**——`vqv` 受 `min_video_duration_ms` 门槛约束；前 3 秒抓人保完播。

## 减分·负信号

`negative_sum = −(not_interested + block + mute + report + not_dwelled)`

- 🟢 别引发 `not_interested`——标题党、话题乱跳、与人设不符最容易被点。（= 身份纪律）
- 🟢 别引发 `block`/`mute`——刷屏、硬广。
- 🟢 别让人划过不停留——`not_dwelled` 本身就是负权重，**开头平淡 = 主动扣分**。

## 多样性 & 排序

- 🟢 **拉开发布间隔**——避开多样性衰减；别扎堆发。
- 🟢 **每条推独立站住**——排序用 candidate isolation，推不靠彼此加成（thread 每推自立、自带 hook）。
- 🟡 **建立真实互关/互动**——有 mutual follow score hydrator，真实关系图被喂进模型。（= P4 支柱）
