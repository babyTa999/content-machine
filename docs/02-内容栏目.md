# 02 · 内容栏目 —— 身份锚下的产出类别

> 主线见 `01-选题哲学.md §2`：AI for〔science research labs + deeptech startups〕，verification 内核。

## 🔑 贯穿原则：PROBLEM-FIRST（2026-07-24 Selene 定死）

**每个栏目找的都是 PROBLEM / 痛点 / 共鸣——让 ICP（science lab + deeptech 的人）刷社媒时对"这个问题 / 这个危险"有痛感、先 problem-aware。然后我们才说 solution 和 product。**

- ❌ 不自卖自夸（找一篇"讲验证/深度研究重要"的论文 = 变相吹我们强）
- ❌ 不 showcase 论文当选题（arXiv 方法论文对这个目标基本是错的源）
- ❌ 不夸人、不踩竞品（含垂类竞品）
- ✅ 找的是"卧槽这就是我的痛 / 这太可怕了"——让 ICP 先意识到 problem 的存在和代价

## 三条内容分类命名（走 hashtag + 系列名，不用 X List）
- **Apodex4Science** —— science research labs
- **Apodex4DeepTech** —— deeptech startups（预测类难题多在此）
- **ApodexSolvers** —— C 端用户 UGC

---

## ① 难题求解（主池）
- **内容**：**science lab + deeptech 的人真正卡住的硬 PROBLEM**——没人解开的、代价极高的、决策两难的真实难题。目标：ICP 刷到"这就是我的痛"→ problem-aware，**之后**才引出 Apodex 跑 + 怎么验证。
- **含"预测切面"（别忘）**：7+5 类专业预测难题——市场竞争情报 / 政策监管 / pharma 临床 / 技术趋势与产品路线 / 供应链与地缘 / 战略情景 / 投资概率 + 科研复现 / 资助出版 / 漏洞利用。
- ⭐**现成预测题库**：SSPP（Social Science Prediction Platform）/ DellaVigna 100 项目 **1,482 个预测问题**，66 个有 ground truth——既是题，又是验证 demo。
- ⚠️ **不是**方法论文、**不是**"讲验证/深度研究重要"的论文（那是自夸）。要的是 PROBLEM 本身。
- **形式**：thread（post 版可做"这个问题为什么难"预热）。**信号**：心智 + 收藏 + 曝光。

## ② 验证拆解 / 反 AI 幻觉
- **内容**：**AI 没做好验证、幻觉造成的真实问题 / 案例 / 历史——尤其我们 ICP 行业的**（pharma 剂量错、法律假判例被罚、金融/科研编造数据），这些会酿成严重错误和后果。目标：ICP 对"AI 不验证的危险"有痛感 → problem-aware，**之后**才引出 Apodex 的 verification。
- **来源之一**：AFP pitch 里描述的那些 case（照着去找这类真实闯祸案例）。
- ⚠️ **不是**"讲 verification 重要"的论文（自夸），**是真实闯祸的 case**。
- **形式**：thread。**信号**：收藏 + 评论。

## ③ 世界观（底色，非独立抓取）
- **内容**：discovery model ≠ generative/chatbot 的身份命题。**从老板 blog 搬现成内容**，不外部抓。
- **形式**：post，偶发。**信号**：心智 + 涨粉（稳定人设）。

## ④ 圈内接话（回复 / quote 动作，非发帖）
- **内容**：**找我们能有意义回复的帖子**——
  - (a) **共鸣**：和我们哲学/世界观一致的帖子（verification / discovery 同频）→ 我们顺势共鸣、自陈；
  - (b) **痛点**：有人吐槽一个我们能解的痛点 → 我们借机推荐自己。
- ⚠️ **别再找夸奖帖、别踩竞品（含垂类竞品）**。找的是"共鸣"和"痛点"，不站队。
- **形式**：comment / quote。**信号**：曝光 + profile_click。

## ⑤ ApodexSolvers / SolversOfTheWeek
- **内容**：C 端用户用 Apodex 跑的 prompts 展示，每几周周五一次。
- **来源**：内部 UGC（Selene 供料，不抓）。**形式**：post。**信号**：涨粉（系列）+ 社区 + AFP。

> **Article（内部重大偶尔）**：非日常栏目，团队重大节点再写深文。
